    1. Zuerst: entpacken und starten.

      cd repost-cleaner
npm install
npm start

    2. Dann: im eigenen Browserfenster einloggen.

      @deinnameLaden

    3. Zum Schluss: filtern, auswählen, starten.

      #werbung -freundeEntfernen: 31
